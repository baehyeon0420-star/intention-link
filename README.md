# unity

Unity project for the Intention-Link XR interaction system.

This repository contains the Unity application for receiving EMG data from the ESP32-based MyoWare 2.0 system and converting it into interactive actions in a 3D/XR environment.

## Goals
- Receive EMG data from ESP32
- Visualize real-time muscle activity
- Map EMG signals to interaction states
- Implement Confirm / Hold / Release actions
- Support future XR interaction with OpenXR

## Features
- Serial communication with ESP32
- Real-time value visualization
- Threshold-based interaction logic
- Demo scene for object selection and control

## Planned integration
- ESP32 DevKitC V4
- MyoWare 2.0 Muscle Sensor
- Unity OpenXR
- Hand tracking / gaze-based targeting
